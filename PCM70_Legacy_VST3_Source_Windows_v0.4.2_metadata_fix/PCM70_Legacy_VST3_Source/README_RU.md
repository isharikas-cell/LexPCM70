# PCM70 Legacy — исходный проект VST3 для Windows

Это первая инженерная сборка независимого стереоревербератора, вдохновлённого рабочей концепцией классических цифровых Lexicon-процессоров.

**Важно:** это не официальная эмуляция Lexicon PCM 70, не содержит оригинального кода, прошивки или заводских пресетов Lexicon и не является продуктом, одобренным Lexicon. Название используется как ориентир проекта.

## Что реализовано в прототипе

- Формат VST3, стерео вход/выход.
- Параметры автоматизируются хостом.
- Сохранение/восстановление состояния проекта.
- Четыре стартовых варианта: Concert Hall, Rich Plate, Warm Room, Ambience.
- Регуляторы Decay, Size, Predelay, Diffusion, HF Damping, Modulation, Width, Mix, Input, Output.
- Интерфейс в тёмной винтажной аппаратной стилистике.

DSP в этой версии — собственная базовая алгоритмическая реализация. Это стартовая версия, а не законченная точная модель PCM 70. Перед релизом необходимы прослушивание, настройка алгоритмов, проверка устойчивости и тестирование в целевых DAW.

## Сборка на Windows 10/11 x64

Нужно установить:
1. Visual Studio 2022 Community с компонентом **Desktop development with C++**.
2. CMake.
3. Git.

Затем откройте PowerShell в папке проекта и выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build_windows.ps1
```

CMake автоматически загрузит JUCE 8.0.6 из официального репозитория и соберёт VST3.

Готовый пакет ожидается здесь:

`build\PCM70Legacy_artefacts\Release\VST3\PCM70 Legacy.vst3`

Скопируйте папку `.vst3` в стандартную папку VST3:

`C:\Program Files\Common Files\VST3`

Затем обновите список плагинов в DAW.

## Сборка через GitHub Actions

В репозитории есть workflow `.github/workflows/build-windows.yml`. После загрузки проекта в GitHub можно запустить Actions → Build Windows VST3. Скомпилированный VST3 появится в Artifacts запуска.

## План следующих версий

- Отдельные алгоритмические движки Hall / Plate / Room / Ambience.
- Более развитая сеть диффузии и ранних отражений.
- Раздельные времена затухания НЧ/ВЧ.
- Более сложная стереомодуляция и корреляционный контроль.
- Заводские программы, A/B, undo/redo и управление MIDI/automation.
- Проверка CPU, денормалов, стабильности обратной связи и звучания на 44.1–192 кГц.
- Валидация VST3 и тесты в Cubase, Reaper, Studio One и Nuendo.

## Лицензии

JUCE используется как внешняя зависимость и загружается CMake из официального репозитория. Проверьте актуальные условия лицензирования JUCE перед коммерческим распространением.


## Изменения DSP 0.2

- Четыре параллельные feedback-линии на каждый канал.
- Два all-pass каскада для повышения плотности.
- Четыре ранних отражения с регулируемым pre-delay.
- RT60-ориентированный расчёт обратной связи для каждой линии.
- Раздельные состояния демпфирования для линий и стереоканалов.
- Стерео-ширина и небольшая синусоидальная модуляция времени чтения.

Это всё ещё экспериментальный алгоритм. Его нужно прослушать и измерить; точное сходство с оригинальным PCM 70 не заявляется.


## DSP 0.3 — безопасное управление уровнями

- Плавное изменение Mix, Input и Output (25 мс), чтобы избежать резких скачков при автоматизации.
- Удалены неиспользуемые локальные данные из DSP-цикла.
- Параметры уровня обновляются без выделения памяти в аудиопотоке.

### Текущий статус проверки

Исходники обновлены, но сборка JUCE/VST3 в этой среде не выполнялась. Поэтому этот архив нельзя считать проверенным бинарным плагином. Следующий обязательный этап — компиляция на Windows x64 и тестирование в DAW, затем прослушивание и измерение хвоста/частотного затухания.


## Сборка и установка (версия 0.4.0)

На Windows 10/11 x64 установите Visual Studio 2022 с компонентом **Desktop development with C++**, CMake и Git. Затем откройте PowerShell в каталоге проекта и выполните:

```powershell
.\build_windows.ps1
```

Скрипт проверит, что создан пакет `build\PCM70Legacy_artefacts\Release\VST3\PCM70 Legacy.vst3`. Для установки в системный каталог VST3 откройте PowerShell **от имени администратора** и выполните:

```powershell
.\install_windows.ps1
```

Удаление:

```powershell
.\uninstall_windows.ps1
```

Также настроена GitHub Actions-сборка Windows x64: после публикации репозитория запуск `Build Windows VST3` создаёт ZIP-артефакт `PCM70-Legacy-Windows-x64-VST3`. Это позволяет получить бинарный пакет на Windows runner, даже если локальная среда разработки не имеет доступа к GitHub.

### Изменения 0.4.0
- Плавное изменение Decay, Size, Predelay, Diffusion, HF Damping, Modulation и Width (35 мс), чтобы избежать резких скачков параметров в аудиопотоке.
- Добавлена реальная слабая перекрёстная связь стерео-резонаторов с задержкой на один сэмпл.
- Убрано чередование полярности суммируемых задержанных отводов; применены положительные нормированные веса.
- Добавлены Windows-скрипты установки/удаления и проверка наличия VST3 bundle в CI.

**Статус качества:** 0.4.0 — инженерная alpha-сборка. Она ещё требует компиляции на Windows, проверки VST3 validator/pluginval, прослушивания на разных частотах дискретизации и тестирования в целевых DAW. Названия режимов описывают независимые авторские voicings сети задержек, а не подтверждённую побитовую или схемотехническую копию Lexicon PCM 70.
